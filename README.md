# 🌿 Pocket Sanctuary

> *Kendi küçük dünyan. Sadece sen ve doğa.*
> *Your tiny world. Just you and nature.*

A cozy, relaxing mobile game concept where you tend to a magical forest sanctuary. No timers, no competition, no losing — just peaceful exploration and connection with nature.

---

## 🎮 Concept

Pocket Sanctuary is a **cozy fantasy idle/exploration game** set in a handcrafted forest sanctuary. The world exists and evolves whether you're present or not. Animals have daily routines, weather changes naturally, and rare magical events occur unexpectedly.

### Core Philosophy
- ⏳ **No time limits** — stay as long as you like
- 💚 **No competition** — only peace
- 🎯 **No losing** — just exploration
- 🌙 **Self-paced** — the game plays at your rhythm
- 📶 **Offline play** — everywhere you go

---

## ✨ Features

### Living World
| Feature | Description |
|---|---|
| 🐦 Birds fly | Animals react to your presence |
| 🍂 Leaves fall | Seasonal changes over real time |
| 💧 Water ripples | Dynamic weather system |
| 🔥 Fire crackles | Ambient sound and visuals |
| ⭐ Stars glow at night | Full day/night cycle |

### Weather System
- ☀️ Sunny
- 🌧️ Rainy
- ❄️ Snowy
- 🌈 Rainbow (rare)

### Gameplay Modes
| Mode | Description |
|---|---|
| 🔍 **Keşfet / Explore** | Find hidden surprises |
| 📦 **Topla / Collect** | Gather natural resources |
| 🎵 **Dinlen / Rest** | Open lo-fi music, relax |
| 🤲 **Dokun / Touch** | Nature interacts with you |
| 📸 **Anları Yakala / Capture** | Take photos, build memories |
